# TuPrimeraPagina+Ferrante

Web creada en Django para el curso de Python de Coderhouse.

Apenas entramos a la web vemos la navbar con las secciones "Inventario", "Marcas" y  "Categorías"
Justo debajo de esto hay 2 botones, el de "Nuevo Componente" y "Ver Catalogo"


- Para crear un **Nuevo componente** primero hay que crear una **Marca** y una **Categoria** en sus respectivas secciones accediendo desde la navbar, sino no se le puede asignar al momento de crear el componente
